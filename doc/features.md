# Feature records

Each app keeps its own record of what is implemented, what is
outstanding and how it was validated:

- [erllama, the library](../apps/erllama/doc/features.md): tensor
  parallelism, drafting with a model's MTP head, and what was measured
  on which hardware;
- [erllama_server](../apps/erllama_server/doc/features.md): the
  service API, runs, models, the HTTP APIs, conversations, agent
  sessions, MCP, the terminal, and shared serving.

What each release changes is in the CHANGELOG of each app.
