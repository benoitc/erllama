# erllama has moved

`erllama` is now **Barrel Inference**, developed in one monorepo under the
neutral `barrel-platform` org.

- New home: https://github.com/barrel-platform/barrel_inference
- This runtime: https://github.com/barrel-platform/barrel_inference/tree/main/apps/barrel_inference

The OTP-native inference runtime (dirty NIFs over llama.cpp, supervised model
processes, token-exact tiered KV cache) continues there as the `barrel_inference`
package. This repository is archived and read-only; its full history is preserved
in the monorepo under `apps/barrel_inference/`.
